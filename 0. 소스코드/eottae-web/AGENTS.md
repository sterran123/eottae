# AGENTS.md — 「어때?」 실행 에이전트 진입점
1. 프로젝트 루트(이 폴더의 상위) `1. 프로젝트 계획서/AI_협업_지시문/RULES.md`, `SKILL.md`, 담당 `AGENT_*.md`를 먼저 읽는다. Git 클론 시 이 파일들도 저장소에 포함된다.
2. 정식 기능 ID `2. 프로젝트 설계서/요구사항_마스터.md` 및 `API_계약_초안.md`를 사용.
3. 이번 스프린트는 김민기의 **홈·브랜딩·반응형·PWA 기본 틀** 담당. 팀원 API·채팅 변경 금지.
4. 3개 서비스는 **한 사이트 한 브랜드**; 1차 매칭만 구현 대상, 2차·3차는 준비중.
5. 사용자 실사용 1:1 로맨스 매칭에는 검증된 만19세 이상 서버 게이트 필수. 미인증 상태에서 데이터 개방 금지.
6. 현재 코드의 상태는 skeleton only이며 실제 로그인·매칭·채팅·결제/푸시는 미구현.
7. 변경마다 실제 실행 테스트/미실행 항목을 구분하여 기록.
8. **의무**: 작업 완료 시 `docs/AI_REPORT_LOG.md`에 `## 날짜 주제 (본인 이름 작업)` 형식으로 기록한다. 형식·태그·지시문 템플릿은 `docs/AI_에이전트_협업_가이드.md`를 따른다.
9. **의무**: `main` 직접 push 금지. `feat/{요구ID}-*` 브랜치 → PR. PR은 CI(typecheck+build) 통과 필수이며 CODEOWNERS가 담당자 리뷰를 자동 요청한다.
