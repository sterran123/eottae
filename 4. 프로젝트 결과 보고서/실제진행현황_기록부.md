# 팀 프로젝트 결과보고서 작성 전 상태표
**현재 단계: 중간 점검 2차 (2026-11-02). 1차 매칭·채팅과 2차 데이트·소모임은 데모. 실연동은 최종 제출 전.**
- **구현 이미지 19장 확보**: 경로 `3. 구현 이미지(5장이상)/`. captions.csv 촬영일은 대부분 2026-10-27~10-29이고, 온보딩 08·09는 2026-11-02. `/activities` 데모 캡처는 없다(05는 2026-10-27 준비중 화면).
- **채팅·신고/차단**: 클라이언트 화면은 데모 데이터로 동작한다.
- **서버 효력 미구현 (PASS 표기 금지)**: 실시간 송수신, 신고 이력 저장, 차단의 서버 효력은 미구현이다. 여기에는 PASS를 쓰지 않는다 (TC-008·010 BLOCKED, TC-009 클라이언트 잠금만 PASS).
- **Android 오프라인**: 본인 재측정이 아니며, `테스트_케이스_마스터.md:36`의 TC-012(2026-10-28, 김민기 실기기) PASS를 인용만 한다.
- **주한태 담당 범위**: 로그인 UI는 PR #57. 성인 확인·결제·매칭의 실연동은 주한태 담당이며 이 문서에서 완료로 올리지 않는다. `0003_match_core.sql`은 저장소에 있다. PR #66은 `TEAM_ACTIVITY.md` 2026-11-02 16:08 집계에서 열린 PR이다. 로컬 pgTAP·클라우드 db push는 아직이다.
- **2차/3차 모듈**: `/activities`는 2026-11-02 데모(PR #69, 아래 행). 청첩장 테마 모의 결제 화면은 저장소에 있다. PR #68은 그 집계에서 열린 PR이다. 실제 청구는 없다. 청첩장 본 기능은 3차.
