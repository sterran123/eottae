# 팀 프로젝트 기획안 — 어때? v1.0
**상태: 계획/기본 골격 · 실제 기능 개발/검증 전**, 작성 2026-10-23.

## 비전과 제품 정의
취향이 맞는 사람과의 **첫 매칭**, 오프라인 **데이트·소모임**, 관계가 이어질 때 사용할 수 있는 **모바일 청첩장**을 **하나의 PWA 웹앱 「어때?」**에서 제공한다. 3개의 별도 앱/도메인/회원 DB를 만드는 것이 아니다.

### 출시 순서 고정
- 1차 MVP: **매칭 앱**. 취향 프로필/공통 질문/카드 추천/쌍방 동의/1:1 채팅/신고 차단, 성인 19+ 검증.
- 2차 MVP: **데이트·소모임 앱**. 활동·데이트코스 탐색, 소모임 생성/참가, 일정 투표, 모임 관리·안전.
- 3차 MVP: **모바일 청첩장 앱**. 청첩장 에디터/테마/초대장 공유/행사 장소·일정/RSVP/방문객 개인정보 통제.

## 1차 범위·브랜딩
새 통합 메인(`/`)에 3개 서비스를 소개. `/match` 개발 대상, `/activities`와 `/invitations`는 준비중 화면. 공통 헤더·로그인·설정·약관·브랜드 로고·라이트/다크 모드의 확장 가능한 틀을 먼저 만든다. `어때?` 로고 원본 2종 사용, 더 차분한 다크 컬러 변경은 후속 디자이너 작업.

## 10~40대 접근과 안전
브랜드 가독성과 공개 서비스 안내는 10~40대를 고려하되, **로맨스 매칭·1:1 채팅은 만19세 이상 검증 사용자 전용**. 미성년자를 성인 매칭에 섞지 않고, 법률·개인정보 보호·운영 정책 합의 전 청소년 소셜 기능을 공개하지 않는다.

## 기대효과 / 수익화 실험
1차: 취향 질문으로 대화 시작 장벽 완화. 구독/추가 관심표시 등은 **가격 가설이며 실제 결제 미구현**.
2차: 모임장 관리 구독/이벤트 홍보·제휴, 장소 DB 상업이용 허용 확인.
3차: 모바일 청첩장 테마 판매·고급 꾸미기. 결제·청약철회/환불·개인정보 정책은 실판매 전 검증.

## 성공 지표(목표의 가설, 실측 아님)
온보딩 완료율, 상호 매칭률, 24h 첫 대화율, D7 재방문율, 유효 신고 대응 시간, 차단 후 발신 0건. 실제 운영 트래픽 없이 지표 수치를 주장하지 않는다.
