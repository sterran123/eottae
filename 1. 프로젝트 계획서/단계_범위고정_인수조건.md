# 제품 범위 고정: 통합 서비스와 3단계 MVP

| 항목 | 1차 MVP: 매칭 | 2차 MVP: 데이트·소모임 | 3차 MVP: 모바일 청첩장 |
|---|---|---|---|
| 공통 단일 계정/탐색/브랜드 | 구축 기반 | 재사용 | 재사용 |
| 메인 홈 3개 카드 | 공개(상태 명시) | 각 카드 개통 | 각 카드 개통 |
| 취향 프로필/추천/질문 | 구현 목표 | 연동 | 필요시 약식 활용 |
| 쌍방 동의·1:1 채팅 | 구현 목표 | 이미 연결된 상대와 이벤트 공유 | 초대장 링크 공유는 별도 동의 |
| 데이트 장소/소모임 찾기 | 준비중 안내 | 구현·테스트 후 개통 | 관련 이벤트만 연결 |
| 모임 일정 투표/신청/참석 | 준비중 안내 | 구현·테스트 후 개통 | RSVP 재사용하되 별도 접근 권한 |
| 청첩장 편집/미리보기/RSVP | 준비중 안내 | 준비중 안내 | 구현·테스트 후 개통 |
| 결제/수익화 | 가격 가설/기능 흐름 검증 | 모임 운영/제휴 실험 | 초대장 테마 결제 실험 |
| 검증 게이트 | 연령, 동의, 채팅 안전, 인가 | 소모임 안전, 위치 최소화, 후기 관리 | 초대 링크 스팸방지, 참석자 정보 보호, 미디어 삭제 |

## 공통 사용자 여정
홈 → 관심사 기반 성인 매칭(MVP1) → 서로 동의한 사용자가 활동/모임을 탐색(MVP2) → 관계가 발전한 경우 모바일 청첩장 제작 및 초대(MVP3). **모바일 청첩장을 이용하기 위해 기존 매칭 앱 사용 이력을 강제하지 않음**: 3차에서는 독립 진입(일반 커플/가족)도 허용하는 제품 설계.

## 기능 유혹을 통제할 우선순위
- 1차 P0: 연령 게이트·로그인·프로필·추천·좋아요·상호 매칭·채팅·차단·신고·데이터 삭제/검증.
- 1차 P1: 익명 취향 밸런스 질문(선택의 방 차용), 안전한 알림, 간단한 커플 질문(매칭 후만).
- 2차 P0: 모임 생성/신청/관리/일정/지역 검색 + 후기/신고; 14개 아이디어 중 `모임장 비서` 일정 투표를 차용.
- 2차 P1: `우리 사이 레벨업`의 관계 협동 퀘스트, 취향 기반 데이트 추천.
- 3차 P0: 청첩장 템플릿/행사 정보/공개 링크/RSVP/접근 정책/삭제/공유 메타태그.
- 3차 P1: 커플 연대기·테마 꾸미기·축하 메시지. **모두 출시는 안전 검토 후.**

## 출시 Gate (통과 전 배포 금지)
1차: 성인 확인 실패/만료/차단 상태에서 모든 매칭 API deny + RLS 테스트 통과 + 신고 처리 책임자 배정.
2차: 1차 안전 게이트 유지 + 지역 위치 정확도/지도 공급·장소 수정 신고·모임 운영자 조치 정책.
3차: 공개 RSVP 링크가 게스트 개인 정보를 노출하지 않음 + 스팸/봇 제한 + 저작권/행사정보 삭제 정책.
