# SKILL.md — 「어때?」 프로젝트 작업 루틴
이 문서는 리포지터리 로컬 AI 코딩 지침이며 MCP 서버나 자동 설치 플러그인이 아니다.

1. `RULES.md` → `요구사항_마스터.md` → `API_계약_초안.md` → 담당 agent 지시서를 읽는다.
2. 이슈 ID, 오너, 선행 조건, 파일/DB 영향, 테스트를 5줄 이내로 먼저 적는다.
3. 커밋 전에 합의된 타입/DTO/권한 정책을 설계하고 UI 성공/로딩/빈 상태/오류/차단 상태를 작성한다.
4. 서버에서 session/adult verification/account status/block 검사 + RLS를 확인한다.
5. `npm run typecheck`, 프로젝트 설정된 lint/test/e2e만 실제 실행 후 결과를 기록한다.
6. 신규 패키지/네트워크/MCP 접근은 최소권한·팀 합의; 민감한 데이터는 외부 프롬프트에 넣지 않는다.
7. `.env` 금지, mock secrets 금지, 계획을 구현으로 주장 금지.
8. 관련 요구사항/테스트/ADR/화면문구를 함께 갱신하고 PR 승인 전 배포하지 않는다.
