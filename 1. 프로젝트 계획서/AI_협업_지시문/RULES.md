## 비협상 조건
1. 제품은 **단일 PWA '어때?'**. 서비스 메뉴는 `매칭(1차)`, `데이트·소모임(2차)`, `모바일 청첩장(3차)`.
2. 1차에서는 첫 번째만 실제 구현 목표이며, 2/3은 홈 카드/안내만. 팀원이 요청하지 않은 후속 기능을 1차에 억지로 구현하지 말 것.
3. 1차 성인 매칭·1:1 채팅은 **검증된 만 19세 이상만**; client-only gate 금지, 서버/RLS에서도 fail closed.
4. 성인·미성년자가 서로 매칭되지 않도록 함. 10대 타깃 UI ≠ 10대 연애매칭 허가.
5. 차단/신고/사용자 데이터 삭제, 사적 사진 동의와 위치 최소화는 **기능 완료 전 필수**.
6. 소개팅 성공률·취향 일치율 등 가짜 수치/유료 결제/연령 인증을 마치 작동하는 듯 표현 금지.
7. 개발용 fake data는 `DEMO` 라벨/격리 필수, 실제 고객 데이터로 로컬 테스트 금지.
8. 운영 DB, 외부 커뮤니티, 결제·SNS 발송, Git main push, 자동 배포는 담당자 명시적 승인 전 금지.
9. 파일 변경 전 요구 ID/오너/영향 범위를 적고, DB/API 변경은 사전 계약 리뷰.
10. 결과 보고에는 **실제 실행한 테스트와 미실행**을 구분, 근거 없는 '검증 완료' 금지.

## 코드 기준
Next.js App Router + TypeScript strict, Git PR 리뷰, minimal dependencies, `.env.example` placeholder, no secret in browser. 표준 오류 계약/경계 검사. 마이그레이션/rollback/접근성(키보드, 모바일 360px) 고려. 사용자 파일/결과물 절대 무단 삭제·수정 금지.
