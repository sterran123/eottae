# 주한태 — 3차 행사/하객/공개 정책 목업 (INV-002)

**현재 맡은 일: 3차 목업 정책 화면.** 소유자만 편집, 공개 링크 토큰 재발급, 보존 기간 안내, 하객 개인정보 비노출을 **화면 데모**로 지킨다. 서버 API·RLS·마이그레이션은 이번 범위가 아니다. 3차 메인은 오하율, 김민기는 총괄 모니터링.

### 우선 이슈
INV-002 P0, TC-015 목업. 선행: 오하율 `src/lib/invitations/` 타입 PR 머지.

### 파일 소유
`src/components/invitations/` 중 정책 패널(토큰 재발급·보존 안내·하객 목록·비소유자 거절)  
공개 하객 화면의 **명단 비노출** 규칙 (뼈대 라우트는 오하율)

손대지 않음: `supabase/`, `src/lib/server/`, `src/lib/auth/`, 새 마이그레이션.

### 인수
비소유자는 편집·하객 목록을 못 본다. 토큰 재발급 후 옛 링크는 만료. 공개 화면에 게스트 명단·회신·연락처가 없다. 보존 기간 숫자를 지어내지 않는다(DEC-06 미결).
