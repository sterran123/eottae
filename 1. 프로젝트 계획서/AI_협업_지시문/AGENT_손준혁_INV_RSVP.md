# 손준혁 — 3차 RSVP 접근 제어 목업 / QA (INV-003)

**현재 맡은 일: 3차 RSVP 목업과 증빙.** 초대 링크가 없으면 회신 화면이 열리지 않게 하고, 하객별 응답을 타인에게 보여 주지 않는다. 3단계 QA·캡처·`captions.csv` 행 추가. 3차 메인은 오하율, 김민기는 총괄 모니터링.

### 우선 이슈
INV-003 P0, TC-016 목업, SEC-002 캡처. 선행: 오하율 `src/lib/invitations/` 타입 PR 머지.

QA 산출: `3. 구현 이미지(5장이상)/` 신규 캡처, `captions.csv` 행

손대지 않음: 에디터 본문, `ThemePreviewSection` 결제 로직, `supabase/`.

### 인수
