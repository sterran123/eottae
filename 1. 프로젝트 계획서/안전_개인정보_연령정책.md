# 안전·개인정보·연령 정책 의사결정 (출시 전 필독)

## 10대~40대 포지셔닝과 실제 기능 권한
- 브랜드는 연령대에 폭넓게 접근 가능하더라도 **성인 데이팅과 미성년 사용자 매칭은 엄격히 분리한다**.
- 1차 MVP는 성인 19세 이상 전용 1:1 매칭. 연령확인이 불가능한 경우 접근 거부(fail closed).
- 10~13세에게 계정/채팅/매칭을 제공하지 않는다. 법정대리인 동의 검증 등이 요구되는 영역은 설계만 하고 미출시.
- 14~18세는 성인 매칭·단독 1:1 채팅을 사용할 수 없음. 공개 정보·비개인화 퀴즈만 가능하도록 검토(1차 기본은 비로그인 읽기 전용).
- 미래 청소년 모듈 별도 개발 시 연령별 위험 평가, 자동/인력 모더레이션, 법정대리인 요건, 사진/위치 정책을 선검증.

## 회원 보호 필수 체크리스트
- [ ] 성인 서비스 서버측 연령 게이트 및 검증 상태, 클라이언트 JS 수정으로 우회 불가
- [ ] 신고/차단 즉시 적용 및 대화 재개 불가; 탈퇴·재가입 악용 방어
- [ ] 공개 프로필 상세 연락처·주소·학교·직장·실시간 위치·정밀 좌표 기본 불허
- [ ] 사진 공개는 상대와의 쌍방 동의 뒤, 개인/사진별 공개 권한 관리
- [ ] RLS/권한 검사: 상대 프로필/채팅/신고 내역 접근 차단
- [ ] 로그에 채팅 본문/비밀번호/토큰/신분 확인 정보 저장 금지
- [ ] 개인정보 다운로드/정정/삭제, 보존 정책, 운영자 감사 로그
- [ ] 사용자 신고·차단 접근성, 익명성 오해 방지, 운영자 업무 매뉴얼
- [ ] 위치정보 기능의 법률 검토, GPS 백그라운드 추적 비사용
- [ ] AI 기능 도입 시 AI 생성물 명시 및 상대를 사람처럼 위장하지 않음

## 정식 출시 전에 결정
성인 인증 공급자, 연령/신원 검증 결과 저장 범위, 개인정보 처리방침, 신고 접수 창구/기한, 약관, 운영자 권한, 개인정보 보관 기간, 보안 침해 대응 계획을 검토한다.
