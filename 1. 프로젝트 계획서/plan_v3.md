## 이번 버전 범위 (1차 MVP)
1. **통합 홈 + 공통 PWA 틀** — 로고·내비게이션·로그인·설정(`/settings`)·6가지 테마·오프라인 화면. 2차 `/activities`는 데모(목업)로 들어가 볼 수 있다. 3차 `/invitations`는 준비중 안내가 범위다. 테마 모의 결제 화면은 저장소에 있다. PR #68은 `TEAM_ACTIVITY.md` 2026-11-02 16:08 집계에서 열린 PR이다. 실결제·RSVP는 미출시
2. **매칭** — 취향·가치관 프로필, 문답·공통 질문으로 궁합 확인, 카드 추천, 쌍방 관심 시 매칭 → 1:1 채팅
3. **안전 장치** — 성인 확인 전·차단 상태면 매칭·채팅 진입 거부, 신고·차단, 차단·탈퇴 사용자는 추천·대화에서 제외, 남의 데이터는 DB 권한 규칙(RLS)으로 차단. 목업 단계(DEC-11)의 공개 배포는 시연용 성인 확인(생일 기준 만 19세) 후 매칭·채팅 데모를 열고, 실데이터 단계에서 시연 바이패스를 지워 fail-closed로 되돌린다. 클라우드 RLS 적용 전이다. 이 항목은 범위 문장이고 완료 문장이 아니다
4. **시연 연동(결정. 2차 제출은 데모)** — 성인 확인·결제의 2차 화면은 예시 데이터 목업이다. BBaton·PayApp 실제 가입·키는 최종 제출 전(주한태). 신분증·OCR 원본은 수집하지 않음

## 완성의 기준
- 로컬 시연 환경에서 서로 다른 두 계정이 회원가입 → 성인 확인(BBaton 시연) → 프로필 작성 → 추천 → 쌍방 관심 → 1:1 채팅까지 **실제 데이터로** 끊김 없이 진행
- 목업 단계(DEC-11)의 공개 배포는 시연용 성인 확인(생일 기준 만 19세, 생년월일 원본은 저장하지 않음)을 거친 뒤 매칭·채팅 데모를 연다. 실데이터 단계에서는 `NEXT_PUBLIC_DEMO_ADULT_BYPASS`를 지워 fail-closed(ADR-002)로 되돌리고, 성인 확인 전 사용자의 매칭·채팅 접근을 거부한다
- 차단된 사용자가 매칭·채팅에 접근하면 거부됨
- 차단한 상대는 추천과 대화 목록에서 사라짐
- 위 과정을 캡처와 테스트 기록으로 증빙 (구현 캡처 5장 기준은 19장으로 이미 충족. 이후 증빙은 실데이터 흐름)
- 성인 확인 시연은 BBaton 연동까지(DEC-01, 2026-10-30). 신분증·OCR 원본은 저장하지 않음(ADR-002). 정식 출시 계약·비용은 미결
- PayApp 실연동(가입·키·실결제 테스트 최대 10회·즉시 취소, 사업자등록 없이, DEC-09)은 최종 제출 전. 청첩장 테마 모의 결제(테스트 결제→승인→즉시 취소 영수증, 실제 청구 없음)는 저장소에 있다. PR #68은 `TEAM_ACTIVITY.md` 2026-11-02 16:08 집계에서 열린 PR이다
