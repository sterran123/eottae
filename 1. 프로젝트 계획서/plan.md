# 어때? (EOTTAE) — 프로젝트 계획 v1
작성일: 2026-10-26 / 상태: 계획·기본 골격 단계 (실기능 개발 전)

## 한 줄 소개
첫 매칭부터 데이트·소모임, 모바일 청첩장까지 관계의 여정을 하나로 잇는 PWA 웹앱 「어때?」

## 목표
- 웹사이트/PWA 1개 + 공통 브랜딩·회원·설정·안전·디자인 시스템 1개
- 사용자 여정으로 연결되는 서비스 3개:
  ① 매칭 `/match` (1차 MVP, 이번 개발 대상)
  ② 데이트·소모임 `/activities` (2차, 이번엔 준비중 페이지)
  ③ 모바일 청첩장 `/invitations` (3차, 이번엔 준비중 페이지)

## 누구를 위한 것인가
- 새 인연·모임·결혼 준비를 한 곳에서 해결하려는 10~40대
- 로맨스 매칭·1:1 채팅은 만 19세 이상 인증 사용자 전용

## 이번 버전 범위 (1차 MVP)
1. 통합 홈 + 공통 PWA 틀 (로고·내비게이션·로그인·설정·라이트/다크 테마)
2. 매칭 앱 — 취향 프로필·공통 질문·카드 추천·쌍방 동의 후 1:1 채팅·신고/차단·성인 인증
3. `/activities`·`/invitations` 준비중 페이지 (실기능 미출시를 솔직히 표시)

## 완성의 기준
- 회원가입 → 프로필 작성 → 추천 → 쌍방 동의 → 1:1 채팅까지 끊김 없이 동작
- 실제 구현 화면 5장 이상의 증빙을 제출할 수 있는 상태

## 역할 분담 (4인 팀)
- 김민기: 전체 기본 틀·공통 사이트 구조·홈/내비게이션/테마·로고·PWA shell·문서 통합
- 오하율: 매칭 프로필·취향·추천 UI/UX 및 접근성
- 주한태: 인증·성인 확인·매칭 API·DB·RLS 보안
- 손준혁: 1:1 채팅·신고·차단·통합 품질 검증/시연 증빙

## 진행 단계
1. 목표 확정 (2026-10-26 완료)
2. 계획 v1 업로드 ← 현재
3. 중간 점검 1차 — 공통 틀 + 통합 홈 동작
4. 중간 점검 2차 — 매칭 핵심 루프(프로필→추천→동의) 동작
5. 최종 제출 — 채팅·신고/차단 포함 전체 시나리오 + 구현 증빙
