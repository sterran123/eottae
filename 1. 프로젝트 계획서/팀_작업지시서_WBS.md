## 작업 순서·완료 기준
- **W1~W2:** 김민기가 기본 골격·공통 홈/로고/라우트·보안 원칙 설정, 전원 요구사항/DTO 합의.
- **W3~W4:** 하율 온보딩 화면, 한태 로그인/DB/RLS, 준혁 채팅 설계, 민기 반응형·PWA shell.
- **W5~W6:** 매칭 추천 카드와 좋아요 API, 성인 검증 연동 설계, 채팅 접근 정책.
- **W7~W8:** 상호 매칭·실시간 메시지/차단·신고, 화면 통합.
- **W9~W10:** E2E·보안·접근성·데모·버그 수정.
- **W11~W12:** 팀 과제 양식, 진짜 구현 스크린샷 5장 이상, 결과보고/최종 발표.

## Git/협업
요구사항 ID로 issue/PR을 생성. main 직접 수정 금지(리뷰 1명 이상), DTO/DB 변경 사전 합의, 민감정보·시크릿 금지, 테스트 실제 실행 결과만 표시. 서로의 담당 파일을 AI가 무단 일괄 덮어쓰지 않는다.
**착수 1번 작업:** 김민기가 CORE-001/002 기본 틀만. 로그인/성인검증/매칭/채팅 등은 다른 담당자와 합의 전 구현 금지.

자세한 백로그/검증값은 `어때_팀_WBS_요구사항_테스트_제출체크_통합관리.xlsx`를 사용.
