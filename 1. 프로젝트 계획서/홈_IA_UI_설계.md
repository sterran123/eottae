# 새 공통 메인 페이지 설계

## 한 사이트·세 가지 진입점
`/`: 브랜드 로고 + 3개 카드 + 제품 설명/안전/가입 안내. 서비스명은 **어때?**
1. `/match` **매칭** (1차 MVP 개발 대상)
2. `/activities` **데이트·소모임** (2차 MVP, 1차 준비중)
3. `/invitations` **모바일 청첩장** (3차 MVP, 1차 준비중)

## 홈 UI 콘텐츠 순서
1. 상단 바: 사용자 제공 로고(라이트·다크 이미지), 3개 고정 메뉴, 안전센터, 로그인 자리.
2. 히어로: "취향이 어때? 같이 만날래? 우리 이야기를 남길래?" + `취향 매칭 알아보기` CTA.
3. 서비스 카드: 카드 1 `1차 MVP 개발중`, 카드 2/3 `추후 개통 / 준비중` 표기.
4. 공통 관계 경험: 취향 선택→공통 질문→쌍방 동의→채팅 → 미래 오프라인 모임 → 미래 초대장.
5. 관계/커플용 추가 기능 후보: 선택의 방(가벼운 대화 질문; 1차 P1), 우리 사이 레벨업(2차 관계 퀘스트), 모임장 비서(2차 일정 투표), 커플 공간 테마(3차 선택).
6. 성인 확인/차단·신고·사진 공개 동의/위치 비공개 설명, FAQ, 개인정보/문의 하단.

## 디자인·접근성
모바일 360/390/430px 우선. 데스크톱 카드 3열. dark mode에서는 검정 배경이 포함된 다크 로고 원본을 억지로 투명이라고 주장하지 않는다. 실제 브랜드 아이콘/다크 파스텔 수정은 별도 기획 작업. 화면은 로딩/에러/미구현/차단/빈 상태를 구분.
