# 「어때?」 브랜드/디자인 시스템 확정 가이드

## 서비스명과 이야기
- 공식 한글: **어때?** (물음표 포함)
- 코드/폴더/환경변수에 쓸 영문 식별자: `eottae` (내부 식별자일 뿐 로고 표기 아님)
- 브랜드 메시지: "취향이 어때? 같이 만날래? 우리 이야기는 어때?"
- 공통 허브 탭: **매칭 / 데이트·소모임 / 모바일 청첩장** — 3개의 앱이 아니라 하나의 통합 PWA.
- 화면 카피는 청소년도 이해하도록 쉬운 한국어를 쓰되 **매칭/채팅은 성인 전용 접근제어**.

## 원본 브랜드 이미지 (첨부 보존)
- `어때_로고_라이트_원본.png`: 사용자가 제공한 첫 로고, RGBA(배경 투명 부분 있음).
- `어때_로고_다크_원본.png`: 사용자 제공 두 번째 로고, 이미지 자체 검정 배경 포함(RGBA 아닌 RGB 수준의 불투명 알파).
- 임의 이미지 생성·리터치 **하지 않았음**. 어둡고 차분한 파스텔로 조정해 달라는 선호는 `BRAND-004` 미완료 태스크에 기록.
- 로고를 늘려 왜곡하거나 의미를 바꿔 생성하지 말 것. 원본 유지, 추후 디자인 검수 후 다크용 투명 변형/앱 아이콘 수동 제작.

## UI 방향 및 WCAG 검사
- Light: #FAF9FE 배경, #28213A 텍스트, #7454C4 CTA, #EECDEB 포인트.
- Dark: #10101B 배경, #F5EEFF 텍스트, #A796D9 보조, 로고는 불투명 검정 배경이 자연스러운 위치에 표시.
- 차분한 파스텔(과한 형광 핑크 금지), 청소년/성인 구분 명확, 텍스트 대비·키보드 포커스·터치 터깃 검증.
- 자동 시스템 다크 모드 대응, 향후 사용자 토글·설정 저장 기능 분리.
- '서로 맞는 취향 92%' 등 알고리즘이 입증되지 않은 수치 사용 금지.

## PWA 아이콘과 로고의 차이
원본은 가로형 브랜드 로고. PWA 설치 아이콘은 192x192/512x512 정사각 규격이 필요하므로 **로고를 정사각으로 억지 크롭하지 않고 별도 제작 후 테스트**. 그 전까지는 설치-ready라고 표시하지 말 것.
