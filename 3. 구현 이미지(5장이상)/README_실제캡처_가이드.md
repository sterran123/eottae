# 실제 구현 이미지 제출 규칙
1차 기능(매칭 실구현)은 아직 미완료 — 현재는 **골격 단계 실제 실행 캡처 7장**(`01`~`07`)이 있다. 이 폴더에 AI 콘셉트 이미지를 구현한 화면으로 넣지 말 것. 아래 3~7번 기능 화면은 해당 기능이 구현된 뒤 추가 캡처한다.

최종 제출 전 **5장 이상 실제 실행 캡처**:
1. `01_공통_홈_데스크톱.png` — 3모듈 통합 네비게이션
2. `02_공통_홈_모바일_다크.png` — 브랜드 로고·반응형
3. `03_성인확인_차단_화면.png` — 미검증 이용자 진입 방어
4. `04_취향_설정_화면.png` — 온보딩 성공/실패
5. `05_추천_카드_질문.png` — 상대 추천/질문
6. `06_매칭완료_대화.png` — 실제 테스트 데이터 쌍방 매칭
7. `07_신고_차단_시나리오.png` — 사용자 보호

모든 캡처에 날짜, 테스트 환경, 해당 TC/요구 ID를 `captions.csv`에 연결. 실사용자 개인정보/신분증/채팅 원문을 올리지 말고 가짜 테스트 계정 사용.
